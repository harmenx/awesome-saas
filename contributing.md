# Contribution Guidelines

Contributions are welcome. This list is a curation of software as a service tools, so please keep additions focused and consistent.

## Adding a tool

- Search existing entries and pull requests before suggesting something new.
- Add something you can recommend, and that fits an existing category.
- Make an individual pull request for each suggestion.
- Use this format: `[Name](https://example.com) - Description.`
- Add the entry at the bottom of the relevant category.
- Link to the product's own website.
- Keep the description short, objective, and grammatical.
- Start the description with a capital letter and end it with a period.
- Do not start the description with the product name.
- Check spelling and grammar, and remove trailing whitespace.
- The pull request should have a useful title, a link to the product, and a short note on why it belongs here.
- New categories should be proposed in a separate pull request.

## Updating your pull request

A maintainer may ask you to change a pull request before it is merged. Update the existing pull request instead of opening a new one. [This guide](https://github.com/RichardLitt/knowledge/blob/master/github/amending-a-commit-guide.md) explains how.

Thank you for your suggestion.
